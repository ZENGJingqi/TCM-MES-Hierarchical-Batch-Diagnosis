# R package requirements

Install the following R packages before running the R analysis scripts:

```r
install.packages(c(
  "readxl",
  "openxlsx",
  "dplyr",
  "tidyr",
  "stringr",
  "lubridate",
  "ggplot2",
  "ggsci",
  "scales",
  "patchwork",
  "pROC",
  "glmnet",
  "xgboost",
  "officer",
  "flextable",
  "pdftools"
))
```

The base R `grid` package is also used.
