# Data availability and local data placement

No raw data or standardized manufacturing datasets are included in this repository.

To rerun the code, place the analysis-ready files in a local data directory that matches the paths expected by the scripts. In the working project, the main standardized data files were:

- `D1_integrated_data_overview_final.xlsx`
- `D2_finished_product_physchem_final.xlsx`
- `D3_finished_product_mes_main_final.xlsx`
- `D4_extract_powder_physchem_final.xlsx`
- `D5_extract_powder_traceability_final.xlsx`
- `D6_aged_tangerine_peel_test_final.xlsx`
- `D7_yam_powder_mes_main_final.xlsx`

These files contain confidential real-world manufacturing, quality-control, MES, and batch-traceability records and should not be committed to GitHub.

External data access may be requested from the authors and is subject to company approval, confidentiality review, and applicable data-use agreements.
